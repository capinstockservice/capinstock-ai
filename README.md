# CapinStock для ИИ-ассистента

Подключите кабинет [CapinStock](https://capinstock.com) к своему ИИ-ассистенту: Claude, ChatGPT,
Claude Code, Codex, Cursor, VS Code и другим. Ассистент будет отвечать на вопросы по вашим товарам,
запасам и закупкам на ваших данных, а не на общих знаниях.

**Адрес коннектора:** `https://mcp.capinstock.com/mcp`

Подключение открывается для клиентов поэтапно. Если для вашей компании оно ещё закрыто, ассистент
скажет об этом сам.

Что можно спросить:

- «Что заказать у поставщиков на этой неделе и на какую сумму?»
- «Где у меня лишний запас и какие товары дают низкую доходность?»
- «Что собрать по FBS сегодня, что просрочено?»
- «Какие платежи поставщикам предстоят в ближайший месяц?»
- «Сколько денег сейчас стоит в товаре и сколько из них реально вложено?»
- «Как в CapinStock дать сотруднику доступ только к складу?»

## Что нужно

1. Оплаченный тариф CapinStock. В демо-доступе коннектор не работает.
2. Право «Экспорт CSV» у вашего пользователя (у администратора компании оно есть всегда).
3. Любой ИИ-клиент с поддержкой MCP — список ниже.

Ассистент видит те разделы, которые входят в ваш тариф и открыты вашему пользователю.
На «Старте» это ФБС, «Честный знак» и номенклатура, на «Базовом» добавляются склады и остатки,
на PRO — план закупок, поставщики, платёжный календарь и доходность товаров.

## Подключение

### Claude (сайт, приложение для компьютера и телефона)

1. Откройте **Настройки → Коннекторы → Добавить свой коннектор** или перейдите по
   [готовой ссылке](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=CapinStock&connectorUrl=https%3A%2F%2Fmcp.capinstock.com%2Fmcp).
2. Адрес: `https://mcp.capinstock.com/mcp`. Если Claude спросит, как представить приложение, выберите
   **«Зарегистрировать автоматически»**.
3. Нажмите **«Подключить»**, войдите в CapinStock и нажмите **«Разрешить доступ»**.

На тарифах Claude Team и Enterprise коннектор добавляет владелец организации, а каждый сотрудник
затем подключает его своим входом в CapinStock.

### ChatGPT

1. **Настройки → Безопасность и вход → Режим разработчика** (Developer mode).
2. На странице приложений нажмите «+», укажите название CapinStock, адрес `https://mcp.capinstock.com/mcp`,
   авторизация — OAuth.
3. Войдите в CapinStock и нажмите **«Разрешить доступ»**.

### Claude Code

Плагин подключает коннектор и навык работы с сервисом одной командой:

```text
/plugin marketplace add capinstockservice/capinstock-ai
/plugin install capinstock@capinstock
```

Затем в сессии `/mcp` → capinstock → вход. Команды плагина: `/capinstock:weekly-review`,
`/capinstock:what-to-order`, `/capinstock:where-to-save`, `/capinstock:fbs-today`.

Плагин из стороннего маркетплейса сам не обновляется. Чтобы получить новую версию:

```bash
claude plugin marketplace update capinstock
claude plugin update capinstock@capinstock
```

Что изменилось в версиях — в [CHANGELOG.md](CHANGELOG.md).

Без плагина:

```bash
claude mcp add --transport http capinstock https://mcp.capinstock.com/mcp
claude mcp login capinstock
```

### Codex

```bash
codex mcp add capinstock --url https://mcp.capinstock.com/mcp
codex mcp login capinstock
```

### Cursor, VS Code, Gemini CLI и другие

Готовые настройки — в папке [`clients/`](clients/).

### Свои агенты и сервисы: n8n, Yandex AI Studio, GigaChat, скрипты

Клиентам без входа через браузер нужен **личный ключ**. Создайте его в кабинете CapinStock:
раздел **«ИИ-ассистенты»** → «Создать ключ». Передавайте ключ в заголовке
`Authorization: Bearer <ключ>`. Ключ показывается один раз и действует 30–365 дней. Отключить его
можно там же в любой момент. Примеры — в [`clients/`](clients/).

## Навык CapinStock

Навык — инструкция для ассистента: какие инструменты вызывать под какой вопрос, как называть
термины, как оформлять ответ. С навыком ответы точнее и короче.

- **Claude Code** — навык входит в плагин.
- **Claude.ai** — скачайте [capinstock-skill.zip](https://github.com/capinstockservice/capinstock-ai/raw/main/dist/capinstock-skill.zip)
  и загрузите его в **Настройки → Возможности → Навыки**. Нужен тариф Pro, Max, Team или Enterprise и включённое
  выполнение кода.
- **Codex, Cursor и другие клиенты с поддержкой Agent Skills** — скопируйте папку
  [`plugins/capinstock/skills/capinstock`](plugins/capinstock/skills/capinstock) в папку навыков клиента.

Короткая версия навыка встроена в сам коннектор, поэтому ассистент без установленного навыка тоже
знает, с чего начать.

## Безопасность и данные

Доступ только на чтение: ассистент ничего не меняет в кабинете.

**Что получает ассистент** — данные разделов вашего тарифа и прав:

- товары: названия, варианты, бренды, группы, размеры, артикулы и штрихкоды на площадках;
- остатки на своём складе и маркетплейсах, их историю;
- заказы FBS: номер отправления, этап, сроки, сумму, город доставки, состав заказа;
- количество кодов «Честного знака» по статусам — без самих кодов;
- склад WMS: зоны, ячейки, движения, недостачи;
- партии закупок: даты, стоимость, платежи, способ доставки и трек-номер;
- поставщиков: название, страну, валюту, условия и цены — без контактов и реквизитов;
- схемы оплаты, себестоимость, платёжный календарь, план продаж, доходность товаров и показатели
  дашборда;
- справку по разделам кабинета из открытой базы знаний CapinStock.

**Чего ассистент не получает:** пароли, ключи маркетплейсов и «Честного знака», банковские
реквизиты, контакты сотрудников и поставщиков, данные покупателей (кроме города доставки), коды
маркировки, формулы, методику и устройство сервиса.

**Куда уходят данные.** Ответы инструментов получает сервис ИИ, который вы подключили (Anthropic,
OpenAI и другие), и обрабатывает их по своим правилам. Подключайте только те сервисы, которым
доверяете свои данные.

**Что хранит CapinStock.** Журнал обращений: время, приложение, пользователь, инструмент, параметры
запроса, объём ответа (без самих данных), IP-адрес и User-Agent. Срок хранения — 180 дней. Журнал
нужен для безопасности и разбора обращений в службу заботы; он виден в разделе «ИИ-ассистенты».

**Если у ассистента подключены и другие сервисы** (почта, браузер, файлы): текст из чужих
источников может пытаться управлять ассистентом. Коннектор CapinStock только читает, но то, что
ассистент прочитал, он может передать в другие подключённые сервисы. Подключайте вместе только то,
чему доверяете, и подтверждайте действия ассистента вручную.

**Лимиты:** до 30 запросов в минуту и 1 000 в сутки на одно подключение, до 3 000 в сутки на
компанию, не больше четырёх запросов компании одновременно. Сутки считаются по Москве.

## Администратору компании

- В разделе «ИИ-ассистенты» видны все подключения сотрудников и журнал их обращений.
- Любое подключение отключается сразу. Выключатель отключает ИИ-ассистентов для всех сотрудников.
- Подключать ассистента могут администратор, сотрудники с полным доступом и с правом «Экспорт CSV».
- Ассистент видит только разделы, открытые пользователю, который его подключил.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| Ассистент говорит, что раздел недоступен | Раздел не входит в тариф или закрыт правами пользователя. Тарифы — на [capinstock.com](https://capinstock.com/index.html#pricing) |
| «Подключение доступно после оплаты тарифа» | Коннектор работает на оплаченных тарифах |
| Ассистент снова просит войти | Подключение отключено в кабинете или не использовалось больше 30 дней. Подключите заново |
| «Слишком часто» или «исчерпан суточный лимит» | Подождите минуту или до полуночи по Москве, сузьте запрос |
| Данные выглядят старыми | Спросите ассистента о свежести данных: инструмент `get_account_overview` покажет время обновления по каждому источнику |

Вопросы — в [службу заботы CapinStock](https://capinstock.com/contacts.html). Как сообщить об
уязвимости — в [SECURITY.md](SECURITY.md).
База знаний о разделах сервиса: [capinstockwiki.tilda.ws](https://capinstockwiki.tilda.ws/).
