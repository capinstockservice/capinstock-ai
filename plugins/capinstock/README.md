# Плагин CapinStock для Claude Code

Плагин подключает к Claude Code ваш кабинет CapinStock — сервис управления товарными запасами и
поставками для продавцов на Wildberries, Ozon и Яндекс Маркете. Ассистент отвечает на вопросы по
вашим остаткам, закупкам, заказам FBS, поставщикам и платежам на ваших данных.

## Что внутри

- **Коннектор** `https://mcp.capinstock.com/mcp` — доступ к кабинету только на чтение.
- **Навык** `capinstock` — какие инструменты вызывать под какой вопрос и как оформлять ответ.
- **Команды** `/capinstock:weekly-review`, `/capinstock:what-to-order`, `/capinstock:where-to-save`,
  `/capinstock:fbs-today`.

## Как пользоваться

1. Установите плагин: `/plugin marketplace add capinstockservice/capinstock-ai`, затем
   `/plugin install capinstock@capinstock`.
2. В сессии откройте `/mcp` → capinstock и войдите в CapinStock.
3. Спросите, например: «Что заказать у поставщиков на этой неделе?»

Нужен оплаченный тариф CapinStock и право «ИИ-ассистент» у вашего пользователя (у администратора компании и
сотрудника с полным доступом оно есть всегда).

## Какие данные плагин отправляет

Плагин ничего не запускает на вашем компьютере. Claude Code обращается к `https://mcp.capinstock.com/mcp`
с токеном вашего входа и получает данные разделов вашего тарифа: товары, остатки, заказы FBS,
партии, поставщиков без контактов, платежи, доходность товаров. Эти ответы Claude Code передаёт в
Anthropic как часть разговора. CapinStock хранит журнал обращений 180 дней: время, инструмент,
параметры, IP-адрес. Подробно — в [README репозитория](../../README.md).
